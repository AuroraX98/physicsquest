# PhysicsQuest 0.10.0 — focused learning and navigation

The prior first explanation often combined multiple relationships and examples, and leaving Apply discarded numerical drafts. The new default supplies one authored short idea/explanation/example; equations use labeled code blocks. Models are reserved for Explore. Original curriculum files and stable lesson IDs remain unchanged.

794 original lessons received short layers. Eight additional lessons bring the total to 802 and numerical practice parts to 562. Added bridges cover units, rearranging equations, probability and five fluid topics. Supplemental prerequisite IDs, units, conditions, examples, quiz and practice answers were reviewed.

Navigation now has exact-step URLs, browser Back/Forward, previous controls, per-course resume, course search with recovery from no matches, meaningful focus, narrow-screen wrapping, and honest load/retry states. Optional local saving and backups include notes, answers and drafts, with existing writing winning on import conflicts. The version-1 storage key and old exports remain compatible.
