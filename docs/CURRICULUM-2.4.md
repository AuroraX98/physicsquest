# Defined curriculum — roadmap 2.4

This finite introductory map has 794 micro-lessons across 15 courses. It is not all physics research, a university qualification or proof of mastery. Course files, tests and the release review ledger establish delivery; naming an objective alone does not establish completion. The eight older course files retain their verified v0.8.0 bytes.

## Remaining-field scope reconciled for this release

The historical seven-field plan contained 344 objectives. Thermodynamics retains all 48 and adds 8 explicit prerequisite/domain bridges, so these seven fields total 352. Other field objective maps are unchanged.
