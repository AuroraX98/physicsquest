# Release 0.8.0 — introductory Quantum III

Quantum III supplies 84 independently reviewed micro-lessons and 68 numerical practice parts. The finite scope develops nondegenerate/degenerate perturbation, variational bounds, WKB, stated effective hydrogen/field corrections, gauge/adiabatic/molecular models, weak transitions and continuum rates, bounded light/open-channel models, and elastic partial-wave/Born scattering. Mathematical bridges are taught locally. Supplied laws/asymptotics, calculations, approximation tests and full derivations are distinguished. This is not all quantum research, a laboratory credential or mastery certified by completion marks.

The app has 442 actual lessons, 376 numerical practice parts, 34 interactive model types and 100 optional glossaries. Three new analytic comparisons cover exact versus second-order two-level energy, a Gaussian trial upper bound for a quartic potential, and central elastic s+p angular/total scattering. Captions distinguish units, undefined zero-shift relative error, trial bounds, amplitude interference, optical-theorem totals and identical-pair counting exclusions.
