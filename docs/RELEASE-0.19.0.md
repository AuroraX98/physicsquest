# PhysicsQuest 0.19.0

## What changed

- All 1,083 lesson questions now have a separate hint for each wrong choice. Try again, or open the answer and see the reasoning.
- All 843 number exercises now offer a hint before the worked calculation. For example, a number with the right size and the opposite sign gets a reminder to check direction.
- Ten new animations follow the values in their lessons. Watch an arrow travel around a globe, a cart change direction, two waves add together, or a clock tick with a flash of light. Each starts paused. You can play, pause, drag the slider or use the keyboard.
- The course map now links to a three-lesson tryout. Measure a shelf, follow a moving belt and carry an arrow around a globe. Explain each idea, change one number and make a prediction. Tryout notes stay in the current tab until you reload or close it. A download button saves a copy.

## Checks

Browser checks covered every lesson at 320 and 1,366 pixels wide, all 3,249 answer choices, and every number exercise. The new animations were checked against their worked examples. Chrome and Edge checks covered the tryout, its notes download and the new hint controls.

The phone checks used simulated screen sizes and touch. Learner testing with real beginners and physical phones remains open.
